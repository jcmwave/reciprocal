reciprocal
==========

``reciprocal`` constructs two-dimensional direct and reciprocal lattices and
samples unit cells, Brillouin zones, and bounded reciprocal space. Its core
geometry and sampling tools use NumPy and SciPy; Matplotlib plotting is an
optional layer.

The package uses right-handed Cartesian coordinates. Direct-lattice vectors
may use any consistent length unit. Reciprocal vectors and wave vectors use
the inverse unit and include the :math:`2\pi` convention.
